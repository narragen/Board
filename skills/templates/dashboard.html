Boundary notes

  • This board renders inside the host app: scripts run in the app's origin, unsandboxed — the owner's explicit decision (D18).
  • Libraries load root-relative from /libs/*, served and version-pinned by the app; the app CSP's connect-src 'self' keeps everything else off the network.
  • Comment affordances are native — hover any section or select text in the browser, then hit the comment button. Keep data-ba markers (and labels, for chip names) on your sections; anything unlabeled gets an id injected at publish.
  • The vote button is type="button" on purpose: the app CSP's form-action 'self' still blocks form submissions leaving the app — this page deliberately stays put.
